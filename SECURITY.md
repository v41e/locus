# Security

## Reporting Security Issues

If you believe you have found a security vulnerability in this repository,
report it through coordinated disclosure.

**Do not report security vulnerabilities through GitHub issues, discussions,
or pull requests.**

Report it privately to the maintainer at
[@v41e's GitHub profile](https://github.com/v41e).

Include as much of the following information as possible:

- A summary and the type of issue
- The affected version, commit, files, component, or surface
- Any configuration required to reproduce the issue
- Step-by-step reproduction instructions
- Supporting proof-of-concept code, logs, or screenshots
- The expected impact and any suggested remediation

This information helps assess and address the report quickly.
