# Task Workflow

Use for maintenance, dependencies, configuration, documentation, refactoring,
or operations that are neither a new capability nor incorrect behavior.

## Phases

| Phase     | Reference                              | Purpose                                     |
| --------- | -------------------------------------- | ------------------------------------------- |
| Scope     | [scope.md](../phases/scope.md)         | Define the proportional work contract       |
| Implement | [implement.md](../phases/implement.md) | Deliver the smallest approved change        |
| Review    | [review.md](../phases/review.md)       | Review through the authorized delivery path |
| Complete  | [complete.md](../phases/complete.md)   | Reconcile and verify the integrated result  |

## Rules

Track meaningful work in the Issue or Project surfaces required by repository
policy. Tiny maintenance may remain untracked when explicit human intent and
the nearest instructions permit it. Do not fabricate Feature ideation or Bug
reproduction.
