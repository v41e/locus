# Feature Workflow

Use for a new or materially expanded capability.

## Phases

| Phase     | Reference                              | Purpose                                          |
| --------- | -------------------------------------- | ------------------------------------------------ |
| Ideate    | [ideate.md](../phases/ideate.md)       | Develop a local draft and optional Project draft |
| Design    | [design.md](../phases/design.md)       | Create the Issue and approved specification      |
| Plan      | [plan.md](../phases/plan.md)           | Create the approved executable plan              |
| Implement | [implement.md](../phases/implement.md) | Deliver the smallest approved change             |
| Review    | [review.md](../phases/review.md)       | Review through the authorized delivery path      |
| Complete  | [complete.md](../phases/complete.md)   | Reconcile and verify the integrated result       |

## Rules

Do not skip Ideate, Design, or Plan because implementation seems obvious or
delivery pressure is high. Resume at the first incomplete phase. A GitHub
Project is optional; use one only when an owning Project exists.
