# Review

Superpowers skills for the Locus Review phase.

## Skills

| Use when                                                                                          | Skill                                        | Boundary                                                 |
| ------------------------------------------------------------------------------------------------- | -------------------------------------------- | -------------------------------------------------------- |
| Subagent-driven implementation reaches its whole-branch review                                    | `superpowers:requesting-code-review`         | Run the required final code review                       |
| A major, security-sensitive, compatibility-sensitive, or pre-merge change lacks equivalent review | `superpowers:requesting-code-review`         | Do not duplicate equivalent review                       |
| Review requests changes                                                                           | `superpowers:receiving-code-review`          | Verify feedback; return to Implement; keep delivery open |
| A plan executor finished and delivery is not governed, or integration otherwise needs a decision  | `superpowers:finishing-a-development-branch` | Preserve human integration ownership                     |
