# Ideate

GitHub actions for the Locus Ideate phase.

## Actions

- For a resumable Feature with an established owning Project, create or
  consolidate one draft in the mapped backlog state.
- Set only its title, body, real assignees, and mapped Project fields.

## Boundaries

- Otherwise leave GitHub unchanged.
- Defer repository, Issue Type, labels, milestone, organization Issue fields,
  and Issue relationships until conversion to an Issue.
