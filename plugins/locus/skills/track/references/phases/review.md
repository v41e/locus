# Review

## Preconditions

The integrated implementation passes its affected checks.

## Workflow

1. Review the result against the approved contract, diff, generated output,
   compatibility boundary, and fresh evidence.
2. Follow the delivery path authorized by repository policy and explicit human
   direction: create or update the pull request, or present the direct change
   for the required review without inventing a pull request.
3. For a pull request, include related Issues, summary, verification evidence,
   and material notes.
4. Apply the mapped review status when tracked work exposes one.
5. Treat requested changes as new Implement work, then repeat deterministic
   verification and integrated review.

## Outcome

Wait for the review and integration required by the authorized delivery path.
Agents do not integrate changes unless the nearest authority explicitly assigns
that responsibility.
