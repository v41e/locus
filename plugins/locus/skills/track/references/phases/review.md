# Review

## Preconditions

The integrated implementation passes its affected checks.

## Workflow

1. Review the contract, diff, generated output, compatibility boundary, and
   fresh evidence.
2. Follow the delivery path set by repository policy and human direction. Create
   or update its delivery record, or present the direct change; never invent one.
3. In a delivery record, include related formal records, summary, verification,
   and material notes.
4. Apply the mapped review status when tracked work exposes one.
5. Verify requested changes, return to Implement, and keep the delivery record
   open. Then repeat deterministic checks and Review.

## Outcome

Wait for required review and integration. Integrate only when the nearest
authority assigns that responsibility.
