# Plan

## Preconditions

The Feature specification is approved and published.

## Workflow

1. Write a short executable local plan with exact owners, files, checks, and
   boundaries.
2. Iterate until the human approves it.
3. Publish the approved plan as a separate Issue comment without its local
   Tracking section.
4. Refresh understood metadata. When a Project item exists, move it to the
   mapped ready state.

## Outcome

Stop at implementation readiness. Continue in the current task or hand off the
approved specification and plan to a separate execution task.
