# Plan

## Preconditions

The Feature design is approved.

## Workflow

1. Define exact owners, files, checks, and boundaries at the depth the work
   requires.
2. For bounded, low-risk work, present the implementation steps inline.
   Otherwise write a short executable local plan, especially for multi-step or
   handed-off work.
3. Iterate until the human approves the plan.
4. Publish an approved local plan as a separate Issue comment only when both
   artifacts exist, omitting the local Tracking section.
5. Refresh understood metadata. When a Project item exists, move it to the
   mapped ready state.

## Outcome

Stop at implementation readiness. Continue in the current task or hand off the
approved design and implementation steps to a separate execution task.
