# Ideate

## Preconditions

A Feature idea exists, but its repository contract is not yet approved.

## Workflow

1. Explore the problem, users, constraints, and desired outcome.
2. Decide whether the idea is one independently prioritizable, resumable
   outcome. Keep questions, minor decisions, tiny maintenance, and subordinate
   steps inside their parent work.
3. Keep early exploration in chat. Store a local artifact only in the repository
   expected to own the resulting change and only when repository context is
   needed to resume the idea independently.
4. When ownership is unresolved, keep the idea in chat or a cross-repository
   Project until repository ownership is decided.
5. When the idea is worth backlog tracking and an owning Project exists, create
   one Project draft using the mapped backlog state and link it from the local
   draft when one exists. Otherwise leave remote state unchanged.
6. When related ideas are consolidated, update the surviving artifacts and
   retire redundant local and Project drafts.

## Outcome

Stop at Design readiness. Do not create an Issue, specification, plan, branch,
or implementation before the idea is ready for formal Design. A missing
Project or local draft does not block Design.
