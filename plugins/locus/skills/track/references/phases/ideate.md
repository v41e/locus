# Ideate

## Preconditions

A Feature idea exists without an approved repository contract.

## Workflow

1. Explore the problem, users, constraints, and outcome.
2. Keep one independently prioritizable, resumable outcome. Fold questions,
   small decisions, maintenance, and substeps into their parent work.
3. Keep early exploration in chat. Create a local draft only in the expected
   owning repository and only when independent resumption needs repository
   context.
4. If ownership is unresolved, keep the idea in chat or a cross-repository
   backlog surface.
5. If the idea merits remote backlog tracking and an owning surface exists,
   create one mapped backlog record and link the local draft. Otherwise leave
   remote state unchanged.
6. Consolidate related ideas; retire redundant drafts and backlog records.

## Outcome

Stop at Design readiness. Do not create a formal remote record, specification,
plan, branch, or implementation. Missing drafts or backlog records do not block
Design.
