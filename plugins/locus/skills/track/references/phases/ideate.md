# Ideate

## Preconditions

A Feature idea exists, but its repository contract is not yet approved.

## Workflow

1. Explore the problem, users, constraints, and desired outcome.
2. Create or evolve one short local draft under the repository's temporary
   artifact convention.
3. Discover whether an owning Project exists. When it does and the idea is
   worth tracking, create one draft using the mapped backlog state and link it
   from the local draft. Otherwise keep Ideate local.

## Outcome

Stop at Design readiness. Do not create an Issue, specification, plan, branch,
or implementation before the idea is ready for formal Design. A missing
Project does not block Design.
