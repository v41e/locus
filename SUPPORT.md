# Support

## Getting Help

1. Read the [README](README.md) and the
   [plugin documentation](plugins/locus/README.md).
2. Search existing [issues](https://github.com/v41e/locus/issues).
3. Gather the expected behavior, reproduction steps, environment, and useful
   evidence without including sensitive information.

## Reporting Bugs

If the behavior is incorrect, open a
[Bug Report](https://github.com/v41e/locus/issues/new?template=bug_report.yml).

## Requesting Features

If you want to propose new behavior, open a
[Feature Request](https://github.com/v41e/locus/issues/new?template=feature_request.yml).

## Proposing Tasks

For maintenance or operational work, open a
[Task](https://github.com/v41e/locus/issues/new?template=task.yml).
